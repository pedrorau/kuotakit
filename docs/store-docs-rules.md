# Rules for answering store questions

Applies to any question about Google Play Billing, the Play Developer API, RTDN, StoreKit 2, the App Store Server API or App Store Server Notifications, whoever answers (a person or an agent; in Claude Code: the `store-docs` subagent).

Answer only from official sources: developer.android.com, developers.google.com, developer.apple.com, and the official Google/Apple client libraries on GitHub.
- Quote or paraphrase the relevant part and give the link for every claim.
- Say which API/library version the answer applies to.
- If the docs do not answer the question, say so. Never fill gaps from memory.
