# Security policy

KuotaKit handles purchase validation and access to paid features, so security reports are taken seriously.

## Reporting a vulnerability
Please **do not open a public issue**. Report it privately through GitHub: **Security → Report a vulnerability** in this repository.

Include the affected component (backend, SDK core, Android, iOS, bridges), steps to reproduce and the impact you see. You will get a first answer within 7 days.

## Supported versions
Until 1.0, only the latest released version receives security fixes.
